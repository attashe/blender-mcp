# Blender MCP (Minimal)

Локальный MCP-сервер для работы с открытой сценой Blender. Клиент запускает сервер через stdio. Аддон принимает команды на `127.0.0.1:9876` и выполняет их по очереди в основном потоке Blender.

| Инструмент | Что получит агент |
| --- | --- |
| `get_scene_info()` | Путь к открытому файлу, версию Blender, режим, единицы, выделение и краткий список объектов. `query="horn"` ищет по части имени без учёта регистра. `objects` ограничивает выборку точными именами, `fields` задаёт нужные поля. По умолчанию выводятся первые 20 совпадений. |
| `execute_blender_code(code)` | Исполнение обычного Python с доступом к `bpy`, `bmesh` и `mathutils`. Результат `print()` приходит в `stdout`. Ошибка возвращает тип исключения, traceback и уже записанные stdout/stderr. |
| `look()` | PNG рабочего вида прямо в ответе MCP. Для проверки формы доступны ракурсы `front`, `right`, `top`, `three_quarter`, изоляция объекта по имени и режим `solid`. Также доступны предпросмотр материалов, активная камера и готовый `render_result`. |

## Подключение

Требуются Python 3.10+ для MCP-сервера и Blender 4.3+ для аддона. Ниже команды для PowerShell из корня этой копии форка.

```powershell
python -m venv .venv
.venv/Scripts/python -m pip install -e .
.venv/Scripts/mcp-for-blender install-addon
```

1. В Blender открой **Edit → Preferences → Add-ons** и включи **Blender MCP (Minimal)**. Если список был открыт во время установки, обнови его. Можно также установить файл `addon.py` вручную через **Install from Disk**.
2. В 3D Viewport нажми **N → BlenderMCP → Start MCP Server**. Если порт уже занят другой версией аддона, выбери свободный порт и передай его MCP-серверу через `--port`.
3. Укажи в конфигурации MCP-клиента абсолютный путь к исполняемому файлу **из окружения этой копии**. Пример для клиента с JSON-конфигурацией приведён ниже. На macOS и Linux исполняемый файл находится в `.venv/bin/mcp-for-blender`.

```json
{
  "mcpServers": {
    "blender-minimal": {
      "command": "K:/Models3D/BlenderScenes/blender-mcp/.venv/Scripts/mcp-for-blender.exe"
    }
  }
}
```

Команда `addon-paths` выводит обнаруженные каталоги Blender. Команда `install-addon --addons-dir PATH` устанавливает аддон для выбранной версии в её каталог `scripts/addons`. При обновлении перезапусти Blender, чтобы загрузить новый код.

## Одна правка

1. Вызови `get_scene_info(objects=["Horn"], fields=["dimensions"])`, чтобы узнать файл и размеры объекта.
2. Выполни через `execute_blender_code` короткую правку. Например, для Bézier-кривой `Horn` смести её последнюю управляющую точку.

   ```python
   horn = bpy.context.scene.objects["Horn"]
   tip = horn.data.splines[0].bezier_points[-1]
   tip.co.x += 0.2
   print(tuple(tip.co))
   ```

3. Вызови `look(view="front", target="Horn", shading="solid")` и проверь силуэт. Для размеров снова запроси `get_scene_info`.

Каждый скрипт получает собственное пространство имён. Объекты и данные Blender сохраняются между вызовами. Для скрипта из проекта можно использовать `runpy.run_path()` с абсолютным локальным путём. Доступ к Python имеет права процесса Blender, поэтому подключай доверенный MCP-клиент.

При исключении предыдущие строки скрипта могли изменить сцену. Если связь оборвалась во время выполнения, сначала проверь результат через `get_scene_info`. Сервер отправляет каждую команду один раз.

Для снимка рабочего вида требуется окно с открытым 3D Viewport. В фоновом процессе `look(view="render_result")` возвращает последний отрендеренный кадр. Полноценный рендер или длительную пакетную обработку удобно выполнять отдельным процессом Blender.

## Проверка разработки

```powershell
.venv/Scripts/python -m pip install pytest
.venv/Scripts/python -m pytest -q
.venv/Scripts/python tests/blender_smoke.py "C:/path/to/blender.exe"
```

Последняя команда запускает отдельный Blender с временным профилем и подключает MCP-клиент через stdio. Он создаёт редактируемую кривую, получает изображение, меняет одну точку, проверяет новый силуэт и размеры, сохраняет файл и проверяет, что запрос сцены работает после ошибки скрипта. Параметр `--images DIR` сохраняет оба PNG.
